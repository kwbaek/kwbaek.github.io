Numbat은 코딩 에이전트 세션에 사전 실행 훅과 규칙 기반 검사를 적용해 시크릿 접근, 권한 상승 같은 위험한 행동을 감시하고 필요하면 차단하는 접근이다. 핵심은 모델이 무엇을 “말했는가”가 아니라, 다음 도구 호출이 실제 시스템에 어떤 변화를 일으키는지를 판단하는 데 있다. 에이전트가 아무리 유창하게 정당화해도 git push, 자격증명 파일 읽기, 네트워크 호출은 별도의 정책 이벤트로 기록되어야 한다. ...

GitHub가 Copilot 사용자의 AI 크레딧 소비를 청구 주기 단위로 확인할 수 있게 했다는 소식은 사소한 기능 추가처럼 보일 수 있지만, 실제로는 AI가 실험 예산이 아니라 운영예산의 항목으로 편입되고 있다는 신호다. “얼마나 잘하느냐"보다 “얼마나 쓰고 있느냐"가 먼저 보이기 시작하면, 조직의 의사결정 방식도 자연스럽게 바뀐다. 이 변화가 중요한 이유는 단순히 과금이 세분화됐기 때문이 아니다. 그동안 많은 팀은 에이전트의 호출 수, 토큰 소비, tool output 길이를 감각적으로만 다뤘다. 그런데 크레딧이 청구 주기 안에서 보이기 시작하면, 팀장은 모델 품질과 함께 사용 패턴을 검토하게 된다. 누가 많이 쓰는지, 어떤 워크플로우가 과도한지, 어떤 에이전트가 같은 결과를 더 적은 비용으로 내는지 비교 가능해진다. 이건 AI를 쓰는 팀에게 꽤 불편하지만, 바로 그 불편함이 운영 성숙도의 시작이다. ...
