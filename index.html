Windows 커널 QUIC: 원격에서 도달 가능한 메모리 안전성 문제로, CVE-2026-33096이 할당되어 Microsoft가 수정했습니다. Linux 커널 네트워킹 스택(CVE-2026-98432): MPTCP 리스너가 있는 서버에 자격 증명 없이, 사용자 조작 없이 패킷만 보내 root 명령을 실행할 수 있습니다. 경쟁 상태(race condition)에서 생긴 use-after-free가 원인이며, 시연에서는 커널 포인터를 유출하는 데 48분, 셸 명령 실행까지 5분이 걸렸습니다. 실패한 경쟁은 시스템 전체를 죽이지 않아 공격자가 반복해서 재시도할 수 있다는 점도 짚었습니다.
