2026년 8월 4일 기준, Y Combinator 산하 소프트웨어 조직 yc-software가 사내에서 실제로 운영해오던 멀티플레이어 AI 에이전트 하네스 QM을 GitHub(yc-software/qm)에 MIT 라이선스로 공개했습니다. 저장소 설명은 “Multiplayer agent harness for work"로, TypeScript 기반이며 공개 직후부터 1만 스타·1,100+ 포크를 넘길 만큼 개발자 커뮤니티의 관심이 집중되고 있습니다. 왜 “멀티플레이어"인가 지금까지 대부분의 코딩/업무 에이전트 도구(Claude Code, Codex, Cursor 등)는 한 사람이 한 개의 에이전트 세션을 운영하는 1:1 모델을 전제로 설계되어 왔습니다. QM이 주목받는 이유는 Slack 같은 팀 커뮤니케이션 채널을 통해 여러 사람이 동시에 하나 이상의 에이전트 인스턴스를 공유·조율하는 워크플로우를 정면으로 다루기 때문입니다. 실제로 QM은 Pi, OpenCode, Codex, Claude Code 같은 기존 에이전트 하네스들을 실행 백엔드로 감싸는 오케스트레이션 레이어에 가깝습니다 — 즉 “새 모델"이 아니라 “여러 에이전트·여러 사람을 하나의 작업 공간에서 어떻게 조율할 것인가"라는 운영 문제에 대한 답입니다. ...
