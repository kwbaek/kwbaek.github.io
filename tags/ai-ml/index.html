AI 회사가 자기 조직을 실험실로 삼아 측정한 자료라서, 수치 하나하나보다 변화의 방향이 흥미롭습니다. 오늘 AI/ML 트렌드 채널에 올라온 스캐너 결과에서도 이 글이 반복해서 보였는데, 그만큼 기업 채용 담당자들이 주목하고 있다는 뜻으로 읽힙니다. 무엇이 드러났나 신입 기술 채용 비중 급감: 기술 부서 전체 인원 중 주니어 비중은 2025년 초 21%에서 14%로 줄었습니다. 같은 기간 주니어 기술 채용(신규 입사자) 비중은 27%에서 9%로 떨어졌습니다. 조직이 커지는 와중에도 주니어 채용만 뚜렷하게 줄었다는 점이 핵심입니다. 에이전트 작업 시간이 사람을 추월: 세션 텔레메트리 기준으로 2026년 3월에 에이전트 작업 시간이 사람 작업 시간을 처음 넘었고, 8월에는 대화형 에이전트 작업 시간이 직원 작업 시간의 여섯 배에 달했습니다. 채용 기준의 이동: 기술 후보자 면접 평가 카드를 분석하니 ‘자율성’과 ‘판단력’에 관한 코멘트가 가장 크게 늘었고, 도메인 전문성에 관한 언급은 줄었습니다. 한 매니저는 모델이 구현을 계속 잘하게 될 것을 전제로 뽑는다고 설명했습니다. 왜 이런 변화가 생기나 생산성 숫자 자체보다 병목의 위치가 바뀌었다는 점이 중요합니다. 같은 보고서에 따르면 코드 커밋 속도는 6개월 전보다 다섯 배가 됐고, 에이전트 출력을 모두 읽는 데 비기술직도 주당 근무시간의 절반이 든다고 합니다. 생산 속도가 빨라질수록 사람의 주의력과 검토 능력이 병목이 됩니다. 실제로 직원들이 작성하는 에이전트 관리 작업(에이전트 스펙 작성, 다른 에이전트 결과 검토, 파이프라인 모니터링)은 2025년 가을 평균 10%에서 2026년 봄 22%로 늘었습니다. ...
