AI/ML 트렌드: 에이전트 행동은 실행 직전에 심사해야 한다 — OpenAI 단계별 안전 검토와 Google 시맨틱 거버넌스 정책

도입: 권한을 잘 걸어도 “요청 범위 밖의 호출"은 남는다 에이전트에 도구를 붙이는 팀이 가장 먼저 쓰는 방어선은 권한입니다. 어떤 MCP 서버에 접근할 수 있는지, 어떤 API를 호출할 수 있는지를 IAM으로 정하는 식이죠. 그런데 실제로 사고가 나는 장면을 보면 권한은 맞는데 목적이 틀린 경우가 많습니다. 파일 공유 도구를 쓸 권한은 있지만, 그 파일이 외부 메일 주소로 나가면 안 되는 실적 자료라면 권한 설정만으로는 막을 수 없습니다. 이번 주 나온 두 발표는 이 빈틈을 서로 다른 층위에서 다룹니다. OpenAI는 2026년 11월 18일 글에서 모델을 훈련부터 배포까지 단계마다 안전 검토를 통과해야 다음 단계로 넘어가는 체계를 공개했습니다. Google Cloud는 Agent Gateway 뒤에 있는 에이전트가 도구를 호출하기 직전에 LLM 심사자가 그 호출을 허용할지 판정하는 Semantic governance policies 프리뷰를 내놨습니다. 하나는 조직이 모델을 내보내는 속도를 조절하는 이야기이고, 다른 하나는 개별 행동을 실행 전에 거르는 이야기입니다. 같은 문제의 두 끝이라고 보면 이해가 쉽습니다. ...
