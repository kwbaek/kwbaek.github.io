AI/ML 트렌드: Claude가 찾은 리눅스 커널 원격 root 취약점 — 발견 속도가 패치 속도를 앞지르기 시작했다

오늘(10/31) 스캔에서 가장 무게가 실린 신호는 새 모델 출시가 아니라 AI 모델이 실제 운영체제 취약점을 찾아 익스플로잇까지 만들었다는 보고입니다. Anthropic Frontier Red Team이 10월 27일 공개한 글에 담긴 사례이고, 서버를 운영하는 팀이라면 패치 일정을 다시 볼 이유가 됩니다. 무엇이 확인됐나 Anthropic은 내부 연구용 모델로 주요 브라우저와 운영체제에서 critical 취약점을 찾았고, 그중 다섯 개의 공격 체인을 공개했습니다. 세 가지 사례가 특히 눈에 띕니다. Chrome: 원격에서 웹페이지를 열면 기본 설정 브라우저가 샌드박스 밖에서 임의 코드를 실행하는 원클릭 체인입니다. 연구진은 이 과정에서 Google에 보고한 62개 CVE가 Chrome 156까지 패치됐다고 밝혔습니다. Windows 커널 QUIC: 원격에서 도달 가능한 메모리 안전성 문제로, CVE-2026-33096이 할당되어 Microsoft가 수정했습니다. Linux 커널 네트워킹 스택(CVE-2026-98432): MPTCP 리스너가 있는 서버에 자격 증명 없이, 사용자 조작 없이 패킷만 보내 root 명령을 실행할 수 있습니다. 경쟁 상태(race condition)에서 생긴 use-after-free가 원인이며, 시연에서는 커널 포인터를 유출하는 데 48분, 셸 명령 실행까지 5분이 걸렸습니다. 실패한 경쟁은 시스템 전체를 죽이지 않아 공격자가 반복해서 재시도할 수 있다는 점도 짚었습니다. Linux 건은 상류 커널에 패치가 들어갔고 유지 중인 안정 브랜치에 백포트까지 끝났다고 합니다. 다만 배포판별 패치 적용 시점은 이 글에서 확인되지 않으니, 각 배포판의 보안 권고를 직접 확인하세요. ...
