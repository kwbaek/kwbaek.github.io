GLM-5.2

오픈웨이트 모델의 사이버 격차가 4~7개월로 줄었다 — 보안팀에 남은 것은 ‘시간’이다

오늘 AI/ML 트렌드에서 가장 묵직한 신호는 새 모델의 벤치마크 순위가 아닙니다. 영국 AI안전연구소(AISI)가 공개한 분석에 따르면, 선도 오픈웨이트 모델의 사이버 능력은 폐쇄형 프론티어 모델보다 이제 4~7개월 뒤에 있습니다. 2025년 내부 평가에서의 6~10개월 격차보다 더 좁아졌습니다. 보안 관점에서 이 숫자는 단순한 성능 비교가 아니라, 방어자가 준비할 수 있는 시간 창이 짧아지고 있다는 뜻입니다. AISI는 2026년 6월 공개된 GLM-5.2가 협소한 사이버 과제에서는 2026년 2월의 Opus 4.6, 긴 호흡의 사이버 레인지에서는 2025년 11월의 Opus 4.5와 비슷한 수준이라고 평가했습니다. DeepSeek V4-Pro 역시 Opus 4.5에 근접했습니다. 여기서 중요한 것은 “오픈 모델이 곧바로 최전선과 같아졌다”는 과장된 결론이 아닙니다. AISI의 평가도 특정 과제와 시뮬레이션 환경에 한정되며, 최근 폐쇄형 모델의 급격한 도약을 미래의 오픈 모델이 그대로 따라갈지 예측하지는 못합니다. ...
