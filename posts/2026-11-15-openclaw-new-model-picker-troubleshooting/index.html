OpenClaw 팁: 새 모델이 목록에 안 뜰 때 — 모델 목록이 나오는 세 가지 경로와 점검 순서

2026년 11월 15일 · map[email: name:Kyungwook Baek]

도입: 모델이 출시됐는데 선택 목록에 없다#

새 모델이 나왔을 때 가장 먼저 드는 생각은 “써 보고 싶다"입니다. 그런데 OpenClaw에서 모델 선택 목록을 열어 보면 방금 발표된 모델이 보이지 않는 경우가 있습니다. 예전에는 이럴 때 OpenClaw 릴리스를 기다리는 것이 답이었습니다. 모델 목록이 플러그인 매니페스트에 들어 있었고, 그 파일은 패키지 릴리스와 함께 배포됐기 때문입니다.

2026년 11월 6일 OpenClaw 블로그는 이 구조를 바꿨다고 설명했습니다. 약 다섯 주 동안 80여 개의 풀 리퀘스트로 모델을 찾는 방식을 다시 만들었다는 내용입니다. 이제 목록은 세 곳에서 채워집니다. 이 세 경로를 알아 두면 모델이 안 보일 때 어디를 확인해야 할지 바로 판단할 수 있습니다.

핵심 신호: 목록은 세 경로에서 온다#

첫째, 호스팅 카탈로그입니다. OpenClaw는 catalog.openclaw.ai에서 모델 카탈로그를 받습니다. 이 카탈로그는 4시간마다 다시 만들어지고, 약 1,000개 모델을 담고 있다고 합니다. 실행 중인 Gateway는 백그라운드에서 새 카탈로그를 확인해 재시작 없이 전환합니다. 다만 진행 중인 턴은 시작할 때의 카탈로그로 끝까지 처리되므로, 모델 목록과 가격이 중간에 어긋나지 않습니다. 종료된 모델이 제공자에서 사라지면 카탈로그에서도 빠집니다.

둘째, 로그인한 계정의 모델 목록입니다. 카탈로그가 공개적으로 존재하는 모델을 안다면, 계정 목록은 내가 실제로 쓸 수 있는 모델을 압니다. 제공자에 로그인하면 OpenClaw가 그 계정이 가진 채팅 모델 목록을 요청해 보여줍니다. 그래서 설치 버전보다 새로운 모델이나 특정 계정에만 열린 모델도 나타날 수 있습니다. Ollama는 ollama pull로 받은 모델이 다음 갱신 때 나타납니다.

셋째, 설치된 Codex 버전입니다. ChatGPT 로그인으로 쓰는 경우, 어떤 모델을 보여줄지는 클라이언트가 보고하는 Codex 버전에 따라 달라집니다. 버전이 낮으면 목록이 짧아집니다. 이 문제 때문에 OpenClaw는 PATH에 있는 Codex를 찾아 쓰는 방향으로 바뀌었다고 밝혔습니다.

왜 중요한가: 목록 버전과 실행 버전이 다르면 더 나쁘다#

블로그에 나온 실패 사례가 교훈적입니다. 첫 번째 수정으로 목록 요청에는 최신 Codex 버전을 보고하도록 했더니, 모델은 목록에 떴습니다. 그런데 실제 턴은 번들된 이전 바이너리로 돌아갔고, 그 바이너리가 매 요청마다 자기 버전을 알려주는 바람에 HTTP 400으로 실패했습니다. 목록에서 실패하던 문제가 첫 메시지에서 실패하는 문제로 옮겨 간 셈입니다. 팀은 이 수정을 되돌렸습니다.

운영하는 입장에서 얻을 수 있는 원칙은 간단합니다. 목록을 만드는 버전과 실제로 실행하는 버전은 같아야 합니다. 목록에 보인다고 바로 쓸 수 있다고 믿으면 안 됩니다.

깊은 분석: 모델이 안 보일 때 점검 순서#

모델이 안 보일 때는 아래 순서로 확인하면 시간을 줄일 수 있습니다.

  1. 계정 확인. 해당 제공자에 올바른 계정으로 로그인되어 있는지 봅니다. API 키로 로그인했다면 그 키의 계정이 모델을 가지고 있어야 합니다.
  2. Codex 버전 확인. ChatGPT 로그인으로 GPT 계열 모델을 찾는 경우, 터미널에서 codex --version으로 PATH의 버전을 확인합니다. 설치된 버전이 오래되었다면 Codex를 갱신합니다.
  3. 로컬 모델 확인. Ollama 모델은 ollama pull이 끝난 뒤 다음 목록 갱신을 기다립니다. 바로 보고 싶다면 목록 갱신 방법을 공식 문서에서 먼저 확인하세요.
  4. 카탈로그 반영 대기. 공개 모델이라면 카탈로그가 4시간 안에 다시 만들어지는지 기다려 봅니다. 그 전에도 카탈로그가 실패하면 해당 제공자 하나만 최신 데이터가 빠지고, 나머지는 정상 동작합니다. 과거 한 사례에서는 제공자 하나의 데이터 누락으로 전체 갱신이 멈춘 적이 있었고, 이후에는 경고만 남기도록 고쳐졌습니다.
  5. 실행 테스트. 목록에 나타난 모델은 짧은 메시지로 실제 턴을 한 번 돌려 봅니다. 목록에 보이는 것과 응답하는 것은 다른 문제입니다.

실무 관점: 장애 대응 메모에 남길 것#

모델 선택 문제가 생기면 “목록에 없다"와 “목록에 있는데 실패한다"를 따로 기록하는 것이 좋습니다. 앞의 경우는 계정, 버전, 카탈로그 중 어디에서 막혔는지를 보는 문제이고, 뒤의 경우는 실행 바이너리와 목록 요청 버전이 어긋난 문제일 가능성이 큽니다. 두 문제를 섞어서 기록하면 다음 번 원인 분석이 어려워집니다.

결론#

OpenClaw에서 새 모델이 보이지 않는다면 먼저 릴리스를 기다리기 전에, 카탈로그, 계정 목록, Codex 버전 중 어디가 막혔는지 확인해 보시기 바랍니다. 이 세 경로를 이해하면 모델 출시일에 기다리는 시간을 크게 줄일 수 있습니다.

출처#

  • Use new models in OpenClaw without an update (OpenClaw 블로그, 2026-11-06) — 카탈로그 4시간 주기, 계정 모델 목록, Codex 버전 문제와 되돌린 수정 사례를 직접 확인했습니다.
  • Codex PATH 동작의 세부 조건은 원문 후반부를 끝까지 확인하지 못했습니다. 그 부분은 실제 설치 환경에서 codex --version으로 검증해 주세요.
